ServerRent — учебный сайт аренды серверов

Файлы проекта:
- index.html — главная страница
- catalog.html — каталог тарифов
- service.html — подробное описание тарифов
- order.html — форма заявки
- contacts.html — контакты
- css/style.css — общие стили сайта
- js/script.js — небольшой скрипт для выбора тарифа и демонстрации формы
- images/ — три SVG-иллюстрации серверов

Чтобы запустить сайт, откройте index.html в браузере или через Live Server в VS Code.
Форма заявки демонстрационная: данные никуда не отправляются.
